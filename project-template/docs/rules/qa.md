# QA 부서 규칙

qa가 판정에 쓰고, PM이 QA 리포트의 판정을 확인할 때 쓴다.

## 버그 심각도와 판정
| 심각도 | 기준 |
|---|---|
| **Critical** | 데이터 손상, 보안 문제, 핵심 흐름 수행 불가 |
| **Major** | 인수 조건 실패, 우회할 수 있는 기능 오류, 중복 제출로 데이터가 2건 생김, 아래 품질 기준 미달 |
| **Minor** | 문구, 표시, 사소한 UI 문제 |

- **PASS**: 모든 인수 조건 PASS, Critical·Major 버그 0건. 그 외는 FAIL.
- **품질 기준** (프로덕션 빌드 미리보기 기준, Lighthouse 모바일 설정, **페이지마다 3회 측정한 중앙값**으로 판정): LCP ≤ 2.5초, CLS ≤ 0.1, TBT ≤ 200ms. INP는 측정할 수 있으면 ≤ 200ms. axe의 serious·critical 위반 0건.
